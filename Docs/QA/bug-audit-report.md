# ผลตรวจและแก้บั๊ก TheElevator

ตรวจเมื่อ 18 พฤศจิกายน 2026 ผ่าน Unity MCP บน Unity 6000.3.11f1
ฉากหลัก: `Assets/TheElevatorLobby/Scenes/Elevator_Lobby_Main.unity`

ผลรอบสุดท้าย: **Play Mode tests ผ่าน 16/16, ไม่ผ่าน 0, ข้าม 0** ใช้เวลาทดสอบ 9.57 วินาที
ตรวจ Console หลังทดสอบไม่พบ error หรือ warning และไม่พบ missing scripts ในฉากหลัก

| ปัญหาที่ตรวจพบ | สิ่งที่แก้ |
| --- | --- |
| Build เริ่มจาก SampleScene แทนแมปล็อบบี้ | ตั้ง Elevator_Lobby_Main เป็นฉากแรกที่เปิดใช้งาน; เก็บ SampleScene ไว้แบบ disabled |
| วัตถุชนกำแพงทั้ง 700 ชิ้นอยู่ Default แต่ตัวควบคุมตรวจเฉพาะ Wall | ตั้ง layer ของ solid colliders เป็น Wall โดยคง trigger ของโซนลิฟต์ไว้ |
| Raycast เลือก NPC ผ่านกำแพงได้ | ตรวจสิ่งกีดขวางก่อนรับการจับ NPC |
| พื้นที่สัมผัส capsule ขวางการลากในแนวราบ | แยกพื้นใต้เท้าและการสัมผัสที่ไม่ขวางทิศทางออกจาก wall hits; ทดสอบว่ายังหยุดก่อนกำแพง |
| จับซ้ำขณะกำลังลดระดับทำให้ค่าพื้นเลื่อนขึ้น | เก็บ GroundY ตั้งแต่การจับครั้งแรก และใช้ค่าเดิมตลอดการจับซ้ำกลางอากาศ |
| การปล่อยหลายครั้งอาจมี coroutine หลายตัวแก้ตำแหน่งพร้อมกัน; ปิดตัวควบคุมแล้ว NPC ค้างกลางอากาศ | ย้ายการลดระดับให้ NPCQueueAgent ควบคุมผ่านสถานะเดียว การจับใหม่ยกเลิกสถานะเก่า |
| เสียโฟกัสหน้าต่างหรือไม่มีเมาส์แล้ว NPC อาจค้างในสถานะถูกจับ | ปล่อยเมื่อเสียโฟกัส ปิดตัวควบคุม หรืออุปกรณ์เมาส์หาย |
| NPC ที่ออกจากคิวไม่นับในเพดานการเกิด ทำให้จำนวนสะสมไม่จำกัด | แยกจำนวนในคิวจากจำนวนที่ยังมีชีวิตทั้งหมด; เพิ่ม maxSpawnedNPCs ค่าเริ่มต้น 24 |
| ลบ NPC แล้วคิวทิ้งช่องว่าง; ทิศคิว/ตำแหน่งเป้าหมายสามารถเปลี่ยนความสูงระหว่างเดิน | ล้างสมาชิกที่ถูกลบก่อนจัดคิว และจำกัดการเดินคิวให้อยู่ในแนวราบ |
| ปิด/เปิด spawner อาจหยุดถาวรหรือมี loop ซ้ำ; prefab ช่องว่างทำให้พลาดการเกิด | จัดการ coroutine ตาม OnEnable/OnDisable และข้าม prefab ที่เป็น null |
| ท่ารับพื้นตัดจบไม่สัมพันธ์กับความเร็วแอนิเมชันที่สุ่ม | คำนวณเวลาท่ารับพื้นตาม PlaybackSpeed |
| กรอบ culling ของบางตัวถูกเลื่อนขึ้นตาม Hips ทำให้ส่วนเท้าอยู่นอกกรอบ และเสี่ยงหายใกล้ขอบจอ | ผูก root ของกรอบกับ Rig ที่อยู่นิ่ง แก้ทั้ง 9 prefabs และ builder สำหรับการสร้างใหม่ |
| ไฟที่คัดลอกเป็น 7 ชั้นร้องเตือน shadow atlas ไม่พอและลดความละเอียดเอง | กำหนดเงา spot lights 63 ดวงเป็นระดับ 256 px ให้เหมาะกับ atlas 2048 px เดิม |

ชุดทดสอบอยู่ใน `Assets/Tests/PlayMode/GameplayRegressionTests.cs` ครอบคลุมการจับซ้ำ/ปล่อย/สูญเสียโฟกัส, การชนกำแพงและพื้น, การเลือกผ่านกำแพง, วงจรเกิดและจัดคิว NPC, แอนิเมชันทั้ง 9 ตัว, กรอบ culling ของทั้ง 11 ท่าที่หลายช่วงเวลา, โครงสร้างแมป 7 ชั้น, เลขชั้น, rendering layers, การสลับกล้อง และตำแหน่งประตูเมื่อเปิด/ปิด

ผลรายกรณีและรหัส test job อยู่ใน `bug-audit-tests.json`

หลังตรวจคืนฉาก Elevator_Lobby_Main ใน Edit Mode ฉากบันทึกแล้ว ไม่มีวัตถุทดสอบตกค้าง และคืนการตั้งค่า Enter Play Mode ตามเดิม

ขอบเขตที่ยังไม่ยืนยัน:

- ยังไม่ได้สร้างและรันไฟล์ Windows player หรือทดสอบบนอุปกรณ์มือถือ
- โมเดลบางตัวมี 0.3–0.85 ล้าน vertices; ยังไม่มี LOD/retopology หรือผล stress test ประสิทธิภาพระยะยาว
- แมปมี 7 ชั้นตามงานคัดลอกแมป แต่ยังไม่มีระบบให้ตู้ลิฟต์เดินทางระหว่างชั้น ปุ่มชั้นยังเป็นองค์ประกอบของแมป
- ชุดทดสอบยืนยันกรณีที่ระบุ ไม่ใช่การรับประกันว่าไม่มีบั๊กทุกเงื่อนไข
